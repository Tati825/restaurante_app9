# restaurante_app9
Nombre: Erika Tatiana España Valdez
La aplicación ha sumado una interfaz gráfica con dos vistas principales siendo LoginView y MainView, donde se ingresa una identificación que esté registrada y la otra permite ver los usuarios y productos disponibles respectivamente. Por otra parte está la carpeta de datos donde están los .json donde se almacena la información; la carpeta modelos donde está la base del sistema (productos y usuarios); la carpeta servicios con la gestión de los datos y main.py que es el punto de entrada.
